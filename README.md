# Times of Lakshadweep

Official news portal for Lakshadweep islands, with integrated **Public Website** and customizable **Editorial Admin Portal**.

Live Site: https://protapi7.github.io/timesoflakshadweep/

---

## 🌟 Key Features

1. **Public Site**:
   - Modern, responsive editorial layout.
   - Breaking news ticker with latest headlines.
   - Real-time search by headline and story content.
   - Categorized stories, read times, and social share buttons (WhatsApp, X, Facebook, Link copy).
   - Light & Dark mode support.
   - Direct button in top utility bar and footer: **🔐 Admin Access**.

2. **Admin Portal**:
   - Direct access via **🔐 Admin Access** button or by visiting `#admin` in your browser.
   - **Default Login Credentials**:
     - **Username**: `admin`
     - **Password**: `mj@010701#`
   - **Full of Customizable Options**:
     - 📰 **Articles**: Write, format, upload images (auto-compressed), categorize, feature on hero, draft/publish.
     - 📑 **Custom Pages**: Add/edit static pages (About Us, Contact, Privacy, etc.) with menu toggles.
     - 🎨 **Site & Branding**: Change publication name, tagline, logo (image/upload), primary & accent colors, typography, footer text, ticker toggle.
     - 📱 **Social & Contact**: Configure WhatsApp channel, Telegram, Twitter/X, Facebook, Instagram, email, phone, and newsroom address.
     - 🗂️ **Categories**: Add, edit, or reorganize news categories.
     - 📢 **Advertising Placements**: Header banner, sidebar, in-article, and footer ads (supporting banner images or Google AdSense/HTML code).
     - 📡 **Source Leads**: Monitor external Lakshadweep news feeds and turn leads into story drafts.
     - 🚀 **Publish Live to GitHub**:
       - **Direct GitHub API Sync**: Enter GitHub Personal Access Token to push updates directly to GitHub from the browser!
       - **Download data.json**: 1-click download of your news data.
       - **Copy JSON**: Copy formatted data to paste into GitHub repository.
       - **Change Admin Credentials**: Update admin username and password securely anytime.
